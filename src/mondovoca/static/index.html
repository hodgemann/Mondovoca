Local model setup


Choose existing local files and Python environments. Saving checks file availability without importing or loading a model. Nothing is downloaded.


Tiny Voca · CPU





Qwen3-TTS · CUDA




The model folder contains Qwen3-TTS-12Hz-1.7B-CustomVoice, Qwen3-TTS-12Hz-1.7B-VoiceDesign and Qwen3-TTS-12Hz-1.7B-Base. Install qwen-tts in its own compatible Python environment. Each checkpoint needs its speech tokenizer files.


AuK · Base · CUDA





Checkpoint folder needs config.yaml, auk_base.safetensors and vae.safetensors. Encoder needs the complete compatible Transformers checkpoint and processor. No automatic weight downloads.


Fish Audio · Drama 3 INT8 · CUDA + RAM






Requires drama3_int8experts_bf16.safetensors and drama3_codec.safetensors. The official Fish runtime cannot load this converted INT8 format. No automatic downloads.


Robin · Fixed Seed · CUDA





One flat folder holding robin_v1.safetensors, robin_vae.safetensors, speech_tokenizer_v3_25hz.onnx, config.json and tokenizer.json; the VAE and tokenizer stay beside the main checkpoint. The voice LoRA is optional and may stay empty. No automatic downloads.




Saved takes


Each take is kept once: in your browser’s download folder or in a folder on this computer.








The chooser opens your system’s folder dialog. Browsers reveal only the chosen folder’s name, so Mondovoca looks for it beside the current folder or inside your home folder. Enter the full path for any other location.


Browser-download mode downloads each finished take automatically and keeps a working copy only while the studio runs, so takes stay playable and can be reused as clone references. Folder mode keeps takes on this computer and does not download them.
